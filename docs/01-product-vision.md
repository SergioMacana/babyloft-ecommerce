# Product Vision

## Proyecto

Baby Loft E-commerce

### Versión

1.0

### Fecha

13 de Julio 2026

### Descripción del producto

Baby Loft E-commerce es una plataforma web orientada a la venta de ropa y accesorios para bebés. El sistema permitirá a los clientes explorar el catálogo de productos, seleccionar variantes como talla y color, agregar productos al carrito de compras y completar el proceso de compra sin necesidad de crear una cuenta.

El proyecto busca ofrecer una experiencia de compra rápida, intuitiva y confiable, al mismo tiempo que proporciona al administrador herramientas para gestionar productos, inventario, pedidos y ventas desde un panel administrativo.

### Problema

Actualmente, las ventas se realizan principalmente a través de redes sociales como Instagram y WhatsApp, lo que implica procesos manuales para:

- Mostrar disponibilidad.
- Confirmar existencias.
- Registrar pedidos.
- Gestionar pagos.
- Hacer seguimiento de las compras.

Estos procesos consumen tiempo y dificultan el crecimiento del negocio.

### Objetivo

Digitalizar el proceso de venta mediante una tienda virtual que permita automatizar la compra de productos y la administración del negocio.

### Objetivos específicos

- Permitir compras sin registro.
- Centralizar el catálogo de productos.
- Administrar inventario por variante.
- Integrar una pasarela de pagos.
- Facilitar el seguimiento de pedidos.
- Reducir el tiempo de atención al cliente.

### Público objetivo

Padres, madres y familiares interesados en adquirir ropa y accesorios para bebés desde cualquier dispositivo con acceso a internet.

### Alcance de la primera versión (MVP)

La primera versión incluirá:

- Catálogo de productos.
- Búsqueda y filtros.
- Variantes (talla, color, etc.).
- Carrito de compras.
- Compra como invitado.
- Información de envío.
- Pasarela de pagos.
- Confirmación del pedido.
- Panel administrativo.
- Gestión de inventario.
- Gestión de pedidos.

### Fuera del alcance (versión 1)

Para mantener el proyecto enfocado, estas funcionalidades se implementarán en futuras versiones:

Lista de deseos.
Programa de fidelización.
Opiniones y calificaciones.
Chat en línea.
Cupones de descuento.
Múltiples monedas.
Aplicación móvil.
Integración con transportadoras.

Nota: La última funcionalidad puede cambiar de prioridad si en el futuro decides automatizar el cálculo del costo de envío.

## Criterios de éxito
- El cliente puede completar una compra sin asistencia.
- El administrador puede gestionar productos y pedidos.
- El inventario se actualiza correctamente.
- Los pagos se registran correctamente.
- La aplicación responde adecuadamente en dispositivos móviles.
