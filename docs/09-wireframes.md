# Wireframes

## Proyecto

Baby Loft E-commerce

---

# Objetivo

Definir la estructura visual de las principales pantallas del sistema antes del desarrollo.

Los wireframes representan la distribución de los elementos de cada página y servirán como guía para la construcción de las interfaces.

# Observaciones

Los wireframes representan únicamente la estructura funcional de cada pantalla.

Durante la etapa de diseño visual se definirán:

- Paleta de colores.
- Tipografía.
- Iconografía.
- Espaciado.
- Componentes de Bootstrap.
- Diseño responsive.

Los wireframes servirán como guía para el desarrollo utilizando Django Templates, Bootstrap 5 y JavaScript.
