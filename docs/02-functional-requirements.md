# Requerimientos funcionales

### RF-001

El sistema permitirá visualizar el catálogo de productos.

### RF-002

El sistema permitirá visualizar el detalle de un producto.

### RF-003

El sistema permitirá seleccionar variantes del producto.

### RF-004

El sistema permitirá agregar productos al carrito.

### RF-005

El sistema permitirá modificar las cantidades del carrito.

### RF-006

El sistema permitirá eliminar productos del carrito.

### RF-007

El sistema permitirá conservar el carrito durante la navegación del usuario.

### RF-008

El sistema permitirá ingresar información de envío.

### RF-009 

El sistema permitirá validar los datos obligatorios antes de continuar.

### RF-010

El sistema mostrará un resumen de la compra.

### RF-011

El sistema permitirá realizar el pago mediante una pasarela de pagos.

### RF-012

El sistema registrará automáticamente un pedido después de iniciar el proceso de pago.

### RF-013

El sistema actualizará el estado del pedido según la respuesta de la pasarela.

### RF-014

El sistema enviará un correo de confirmación después del pago exitoso.

### RF-015

El administrador podrá iniciar sesión.

### RF-016

El administrador podrá crear productos.

### RF-017

El administrador podrá modificar productos.

### RF-018

El administrador podrá eliminar productos.

### RF-019

El administrador podrá administrar variantes.

### RF-020

El administrador podrá administrar inventario.

### RF-021

El administrador podrá visualizar pedidos.

### RF-022

El administrador podrá modificar el estado de un pedido.

### RF-023

El administrador podrá visualizar estadísticas básicas de ventas.
